Jurnal Servis Kendaraan Pribadi by : Maika Izano Filzan

Sistem pencatatan simpel berbasis Python untuk merapikan riwayat perawatan kendaraan pribadi. Dibuat pakai tampilan terminal supaya praktis digunakan tanpa ribet.

Kenapa Bikin Program Ini?
Sering kali kita lupa kapan terakhir ganti oli, servis rem, atau cek rutin kendaraan. Program ini hadir sebagai solusi simpel buat mencatat semua riwayat servis kendaraan dalam satu tempat secara terstruktur.

Fitur & Cara Kerja
Program ini memanfaatkan gabungan struktur data List (sebagai wadah utama) dan Tuple (penampung detail tiap servis). Semua fitur berjalan di dalam menu perulangan (while loop) yang dilengkapi validasi input:

-Lihat Riwayat : Menampilkan daftar semua catatan servis yang sudah tersimpan.
-Tambah Catatan: Menambah riwayat baru (nama/pelat kendaraan, jenis servis, kilometer, dan tanggal).
-Ubah Catatan : Memperbarui data lama jika ada kesalahan atau perubahan.
-Hapus Catatan : Menghapus riwayat servis yang sudah tidak diperlukan.
-Validasi Input : Menjaga program tetap jalan rapi kalau misal salah ketik menu (ngga langsung crash).
